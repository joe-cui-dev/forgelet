# The Reasoning Stream Is a Live CLI-Only Role for Carryover Bytes

ADR 0065 named a model turn's `reasoning_content` **Provider Carryover** and made it opaque: stored, replayed verbatim, never rendered. The live view honoured that literally and forwarded only `bytesSoFar`, so a Session that thought for twenty seconds showed `Model turn 1 thinking: 21555 bytes` and nothing a user could read. We decided that Carryover's opacity is a claim about *Forgelet's own processing* — it does not parse, rewrite, or compact those bytes — and not a claim about whether the person running the Session may watch them. The same wire bytes therefore carry two roles, and we name the second one the **Reasoning Stream**: transient, rendered in the interactive CLI terminal, retained nowhere. Every ADR 0065 invariant survives untouched — the Trace still records byte counts only, the Pause Snapshot still persists Carryover under ADR 0033's bounded-lifetime acceptance, and Carryover is still never rendered *as content*, because a Stream is presentation that the Session's outcome never contains. We rejected the alternative of weakening Carryover's definition to permit rendering, which would have left "opaque" meaning nothing in particular.

Three choices shape the implementation. `ModelReasoningDelta` gains the raw incremental `text`, symmetric with `onOutputDelta`, and all batching moves into the ReAct Node, which buffers deltas as a string and emits at the existing 1 KiB heartbeat; the alternative of slicing the finished `providerCarryover` at the reported byte offset splits multi-byte characters and would corrupt any non-ASCII reasoning. The Node flushes that buffer when the turn returns, because a throttle that silently drops the sub-heartbeat tail was harmless while it only lagged a counter and truncates the closing sentences once it carries text. And the Browser protocol strips `text` before wrapping the event in a `live_event` frame while keeping `bytesSoFar`: the side panel discards the event today, its projection lives inside ADR 0052's 24 KiB budget that a single turn's thinking would exhaust on its own, and stripping makes CLI-only a property the code enforces rather than a convention two surfaces have to remember. Redirected output needs no further guard — the live view is constructed only when stdout and stderr are both TTYs, and writes to stderr. We rejected streaming every provider delta unthrottled, which would turn one turn's thinking into thousands of native-messaging frames for a consumer that drops them.
