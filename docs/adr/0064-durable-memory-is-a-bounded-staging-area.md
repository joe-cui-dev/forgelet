# Durable Memory is a Bounded Staging Area, Not a Second Layer of Guidance

`forge memory suggest` has been available for the whole dogfood history and has produced nothing: across 296 Sessions in the dogfood workspace there are zero Memory Suggestions, zero Memory Decisions, and `.forgelet/memory.md` has never existed. The cause is not selection quality but supply. The only generator, `formatActionableAuditMemory` in `src/memory/index.ts`, derives from actionable-audit evidence alone — only 8 of those 296 Sessions recorded `changedFiles` and only 10 recorded a command `exitCode`, so ~97% of Sessions cannot produce a suggestion at all — and the one sentence it can emit ("after changing X, use `npm test` as verification") is already stated in `AGENTS.md`, with the reasoning and the prohibition the generated line lacks. Durable Memory was restating declared guidance, into the same prompt that already carries `AGENTS.md` as an Anchor File (ADR 0031).

We therefore draw the boundary by provenance rather than by content: **`AGENTS.md` holds guidance the user declared up front; Durable Memory holds only conventions discovered in real Sessions that are not yet declared there**, each traceable to a source Session. A discovered entry that proves itself is moved into the declared guidance and deleted from Durable Memory — Memory Graduation (see CONTEXT.md) — because at that moment it has become declared, and keeping it in both places is duplication. Durable Memory is consequently a bounded staging area, small by construction, and the existing whole-file injection into the stable prompt prefix (ADR 0032) under its 20KB cap remains sufficient indefinitely.

Two consequences follow that are easy to get wrong later. Any future work on the proposal side must first compare a candidate against the Anchor Files — `AGENTS.md`, `CONTEXT.md`, `README.md`, `package.json` — and drop what is already declared; that semantic comparison, not text generation, is the real reason the proposal side would need a model. And Project Memory Review (`forge memory list/show/accept/reject`) stays deterministic and model-free regardless: proposal may become model-backed, the decision surface may not.

## Considered Options

- **Bounded Memory Recall** (previously ROADMAP ladder rung 2: replace whole-file injection with budgeted, relevance-ranked selection recorded as Trace evidence) — rejected. Recall is a selection mechanism over a corpus, and a staging area drained by graduation stays at a few dozen entries. It would have indexed an empty set while leaving the supply problem untouched. Removed from the roadmap by this ADR.
- **A permanent second layer** that grows and is never drained — eventually large enough to justify Recall, but only by keeping declared and discovered guidance side by side forever, which is the duplication we just diagnosed.
- **TTL or reference-count expiry** to bound the layer automatically instead of by hand — requires tracking whether an entry was used, and usage tracking is exactly the Recall infrastructure this decision removes.
- **Merging Durable Memory into an `## Learned Conventions` section of `AGENTS.md`** — a single source of truth is attractive, but it makes Forgelet write the file the user maintains for every agent, not just this one.
- **A `forge memory add` command** for the hand-written entries — `.forgelet/memory.md` is already user-editable Markdown, `loadDurableMemory` treats a missing file as absent so creating it takes effect immediately, and the command would only append a line. Not worth a CLI surface.

## Consequences

Personal Memory Scope is dropped for now along with Recall: the graduation model gives a discovered project convention somewhere to go, and Forgelet has no personal equivalent of `AGENTS.md` for a personal entry to graduate into. The `Memory Scope` and `Memory Recall` glossary entries are removed rather than marked aspirational, because `CONTEXT.md` is itself an Anchor File and a rejected mechanism sitting in it would keep flowing into every Session's Active Context. Reintroducing personal scope means answering the graduation question first.

Until the supply side is fixed, Durable Memory is filled by hand. `.forgelet/*` is git-ignored, so the staging area is local, per-machine, and invisible to a fresh clone or worktree — consistent with a scratch area whose durable output is a committed change to `AGENTS.md`, but it does mean discovered conventions are not shared until they graduate.
